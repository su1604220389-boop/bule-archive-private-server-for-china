# 招募「按了没反应」根因 —— 2026-11-18 22:35 定案

## 一句话
**不是服务端不给，是客户端判定「你付不起这张池子的成本」→ 按钮无响应、一个包都不发。**
而这个池子要的不是宝石，是**一张新手招募券道具**，账号里没有。

## 证据链（每一环都可复核）

### 1. 客户端闸门在本地，且不看服务端下发的 `ShopRecruits`
`il2cpp-analyst` 在真机包里反汇编到明文函数：

- `UIGacha.IsCanBuyGacha` @ `0x09FB86CC`（**明文**）
- 第一句：`0x09FB8990 bl IsShopRecruitOpen(targetExcel, Id, CurrentTime)` → 返回 false 就 `tbz w0,#0`，**跳过整个购买分支**
- `IsShopRecruitOpen` @ `0x0EACBD14`：`TryGetValue(id, out excel)` → 查不到 id 返回 false → 再 `ldrb w8,[x10,#0x1C]`
- ⇒ 判定依据 = **客户端自己 Excel 里的卡池行 + 在期判断**

**这解释了为什么我前面 4 版改服务端 `ShopRecruits` 全部无效**（714 条 / 1243 条 / 官方 529 条 / 补 `ItemListResponse`）。

### 3. 账号里没有这张券
线上 `/root/shittim.sqlite3` 的 `Items` 表：账号 4 共 19 条（UniqueId: 2,3,7,10,11,12,13,40,41,42,80,81,82,83,9998,40003,40000,40001,40002,160000），
账号 2 共 21 条 —— **`11000001` / `11000000` 一条都没有**。

⇒ `IsCanBuyGacha` 判「付不起」→ 按钮无响应 → nginx 上没有 `/api/shop/*` 请求 → 与现象 100% 吻合。

### 4. 为什么文案是 `No LocalizeKey`
本地化表里招募相关文案是齐的（`招募10次`=3515、`招募所需的招募券不足`=768、`距离开放剩余{0}天{1}小时`=3264 等），
但客户端拿不到这些 key 的解析（`LocalizeKey` 字面量在 `0x000F4FD5`）。**这是本地化资源问题，与能否招募无关**，单独立项。
