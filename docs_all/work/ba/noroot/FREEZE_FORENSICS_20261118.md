## 4. 占位符 `US name` 的意义
```
「ID卡」里显示的是 **prefab 原始占位串**，不是空白、不是报错
⇒ 本地化表 / UI 资源**没加载出来**，客户端在渲染 prefab 默认文本
⇒ 这与历史上出现过的 `カカカカカ`（字体 fallback）、`textxttextxt`（占位串）是**同一族症状**
⇒ 合理推断：那一屏依赖的 bundle 没拿到，客户端在等/重试 → 主线程忙等 → 硬冻
```
**这条推断必须靠"资源请求状态码"落地，不能只凭症状。**
