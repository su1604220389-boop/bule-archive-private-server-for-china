**改后**（补丁器插入的常量/工具 + 替换头部）：
```python
MAX_REQUEST_BODY = 4194304          # 4 MB（模块顶部，可调）

def _parse_content_length(raw):
    """-> (n, err)。err 非空时调用方必须回 400，不得抛到外层。"""
    if raw is None or str(raw).strip() == "":
        return 0, "missing Content-Length"
    try:
        n = int(str(raw).strip())
    except Exception:
        return 0, "non-numeric Content-Length"
    if n < 0:
        return 0, "negative Content-Length"
    if n > MAX_REQUEST_BODY:
        return 0, "Content-Length %d exceeds cap %d" % (n, MAX_REQUEST_BODY)
    return n, ""
```
```python
    def _handle(self):
        self._log_ingress()
        try:
            n, _cl_err = _parse_content_length(self.headers.get('Content-Length'))
        except Exception:
            n, _cl_err = 0, 'bad Content-Length'
        if _cl_err:
            self._log({..., 'err': 'CL: ' + _cl_err, 'resp_code': 400, 'resp_len': 0})
            self._send(400, json.dumps({'error': 'bad request'}).encode(), 'application/json')
            return
        try:
            body = self.rfile.read(n) if n else b''
        except Exception:
            self._send(400, json.dumps({'error': 'read failed'}).encode(), 'application/json')
            return
```

## 2. F2 · 日志脱敏

| 位置 | 改法 |
|---|---|
| 桥 `_handle` 的 `rec['headers']` | **仅对敏感头**（`mxtoken/sessionkey/openid/token/req_key/req_iv/devid/...`）打码，其余原样 |
| 桥 `rec['req_key']` / `rec['req_iv']` / `rec['req_frag_head']`（含 4 处 fragment 赋值） | 全部包 `mask_secret(...)` |
| `sdkcard.py` 的 `LOGIN OK/REJECT/QUICK OK` 与 `BODY %s` | 卡密与 dev 改 `_mask(...)` |

**打码规则（固定）**：`前4 + "****" + 后4 + "(len=N,sha8=xxxxxxxx)"`；长度 ≤8 时全 `*`。
示例：`Vji5A/Cy6…GbzYBKA` → `Vji5****YBKA(len=64,sha8=96cd4269)`。
**保留可诊断性**：长度、前4后4、sha256 前 8 位都在。

**影响面**：只影响日志文本，不影响协议。
**回滚**：删除 `mask_secret`/`_mask` 的包装调用（搜 `mask_secret(` / `_mask(`）。
