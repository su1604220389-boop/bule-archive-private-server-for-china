## 0. 两条定性结论（写死在这里，避免以后误读）

1. **`EnforceTicketToken = false` 是临时状态，不是设计终点。**
   token 校验的最终形态：**桥做设备级权威校验**（`token == sha256(card|dev)[:40]` + `dev ∈ cards[card].devices` + 卡未过期），Shittim 只保留 **publisher 级稳定握手**。
   用户已拍板「不做 root 机例外，那台也会换我们的包」⇒ **"官方优星 token"这条路会消失，两台机最终同源**，届时"多设备 token 不同"的互踢前提自然消失，`EnforceTicketToken` 才有条件打开。

2. **F1 里的「per-publisher 稳定 token」这一层必须在桥侧先落地（proto-analyst 负责），C# 侧暂不写代码。**
   原因：`publisherId` 是"每卡一个"，token 是"每设备一个"；桥校验通过后要把发往 Shittim 的 Token 归一成 `sha256("bp:"+publisherId)`，否则任何一层做比对都会让多设备互踢。
   **C# 侧的动作只有：等桥稳定一轮 → 把 `EnforceTicketToken` 从 `false` 改 `true`（一行配置）。**

### ④ `Config/config.json` 要不要手工加 `SessionTtlMinutes`

| 选择 | 写入内容 | 结果 |
|---|---|---|
| **不加（推荐先这样）** | — | 缺键 = 属性初始值 ⇒ **`10080`（7 天）**，不会读失败 |
| 想更保守 | `"SessionTtlMinutes": 1440,` | **24 小时空闲**（在线玩家每次请求都刷新 `LastActivity`，不会被踢） |

- 位置：`/www/wwwroot/ba_srv/Config/config.json` → `ServerConfiguration` 节内。
- 不加键也没关系：服务下次 `Config.Save()` 会自动把两个新键写进去，之后就能直接改。
- **不要手工删 `EnforceTicketToken`**：删了也等于 `false`（初始值），但保留更直观。

### ⑤ 重启命令（tmux 那套）

```bash
systemctl restart ba-shittim          # unit 内 ExecStop=tmux kill-session -t shittim，ExecStart=tmux new-session -s shittim
sleep 8
tmux ls                               # 应看到 shittim
tmux capture-pane -pt shittim | tail -20   # 看到开始监听 5000/5100
```

### ⑥ 冒烟步骤（按这个顺序，5 步）

1. **启动检查**：`tmux capture-pane -pt shittim | tail -40` 无异常堆栈、无 `UnauthorizedAccessException`。
2. **登录**：root 机（或任一客户端）完整登录进大厅 ⇒ 正常。
3. **会话存活验证**：进一个关卡、看角色界面 ⇒ 正常（证明 TTL 没把活跃会话误判）。
4. **重启恢复验证**：再 `systemctl restart ba-shittim` 一次，客户端不重登继续操作 ⇒ 正常（`sessions.json` 恢复 + TTL 未误杀）。
5. **观察 10 分钟**，grep 日志关键字：
   - `Session expired or invalid` — **新增**才异常（说明有 <TTL 空闲的会话被判死，把 `SessionTtlMinutes` 调大或设 0）
   - `Session token mismatch` — 新增即异常（会话被顶号）
   - `ACCOUNT_TOKEN_MISMATCH` — **不应出现**（F1 关着；出现说明配置被改过）

### ⑦ 回滚（一行）

```bash
# 一步回滚到改前 DLL + 配置（不改源码、不重编译）
systemctl stop ba-shittim && cd /www/wwwroot/ba_srv && cp -a Shittim-Server.dll.bak.$TS Shittim-Server.dll && cp -a Config/config.json.bak.$TS Config/config.json && systemctl start ba-shittim
```
> 只想关 F2、不换 DLL：把 `SessionTtlMinutes` 改成 `0` 再 `systemctl restart ba-shittim`。
