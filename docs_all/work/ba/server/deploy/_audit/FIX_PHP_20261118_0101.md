## 2. 关键实现说明（为什么这样改）

### 2.1 F1 为什么不是"直接不回显"
`settings.php` 同时是**保存**页：若控件不回传原值，保存别的字段（如 base）会把 key 清空。故采用：
`空值 + 未勾清除 = 保持原值`，需要替换时直接填新值，需要清空时勾选。
「显示一次」用 `secret_once_set/take`：POST 后 302 回 GET，值存 `state/secret_*.json` 并在下次渲染时取走删除——刷新即无，不进 HTML 缓存。

### 2.2 F2 为什么用文件而不是 DB
`admins/ sessions` 表结构是线上既有 schema，本阶段**不允许改库**。令牌用 `state/otok_<hash(session|scope)>.json`：
- 随机 32 hex，TTL 600s；
- `hash_equals` 比较，校验后立即 `unlink`（无论成败）；
- 无令牌/过期/重放 → **419**，不执行任何写操作；
- 每个 `(会话, scope)` 同时只有一个令牌（多标签页只保留最新，属**有意取舍**，见 §6）。

### 2.3 F3 旧值怎么取
- 货币：`ba_account_currencies($sid)` 读现值（`set` 模式原来不读，本次改为都读）；
- 封号：`ba_account_detail($sid)['data']['state']`；
- GM 命令：仅当命令形如 `setaccount <Prop>` 时反查同名属性（大小写不敏感），其它命令无通用旧值，审计记录命令 + 输出；
- 邮件：无"旧值"概念，记录**完整附件 JSON + 收件人 + 批次**。

### 2.4 F4 导出改 POST 的连带修改
`cards_import.php / cards_new.php / dashboard.php` 里原有 4 个 `href="cards_export.php?..."`，改为内联 POST 表单，否则点击会 405。

## 6. 已知取舍与回归点（复审请重点看）

1. **多标签页**：同一 `(会话, scope)` 只有一个有效令牌，旧标签页提交会 419。属有意取舍（防误触），提示语已写明"刷新后重试"。
2. **导出改 POST**：外部书签/旧 GET 链接会 405（站内 4 处链接已同步改）；浏览器"另存为"行为不变（响应仍是附件）。
3. **`ba_admin_key` 留空语义变化**：以前留空会清空 key，现在留空=保持；要清空必须勾选。**这是为配合"不回显"必须做的语义调整**。
4. **审计写入量**：货币/封号现在每人多一次读请求（`ba_account_currencies` / `ba_account_detail`）。批量 100 人 = 多 100 次环回请求，可接受；若担心，后续可只在审计里记 batch 级别。
5. **`settings.php` 的 `reveal_key` 不做 redirect**：走统一的 `redirect_self()`，值靠 `secret_once` 跨请求传递；若管理员并发打开两个设置页，只有后点的一次能显示（正常）。

## 8. 运维方案（只出方案，srv-ops 执行）

### 8.1 `display_errors=Off`（高危信息泄露）

- 文件：`/www/server/php/82/etc/php.ini:508`
- 改：`display_errors = On` → `Off`；保留 `log_errors = On`（第 527 行）
- 生效：`/etc/init.d/php-fpm-82 reload`
- 验证：`php -i | grep display_errors`（FPM 侧可用 `curl` 一个会触发 warning 的路径对比）
- 风险：错误不再显示给用户（应如此）；日志仍在 `/www/wwwlogs/php-fpm-82.log` 类路径。**改前先确认 error_log 路径可写**。

### 8.2 8081 上 TLS（高危：口令/会话明文）

现状：`listen 8081`（无 ssl）、`server_name <SERVER_IP>`，`is_https()` 因此恒 false，cookie 无 Secure。
两条路线（按成本）：

1. **推荐**：绑一个域名到本机 → 宝塔申请 Let's Encrypt → 给该站点开 443/SSL → 强制 HTTPS；8081 只监听 `127.0.0.1`（`listen 127.0.0.1:8081`），由 443 的 `location /panel/` 反代。代码无需改（`is_https()` 已处理 `X-Forwarded-Proto`）。
2. **过渡**：云安全组把 8081 限制为管理员固定 IP + 仅内网；面板继续 HTTP（风险降级但不消除）。

> 不建议自签长期使用（浏览器告警会让人习惯性忽略；且仍可被中间人替换证书）。

### 8.3 文件权限

- `logs/sync.log`：`666` → `640`（属主 www:www）；`logs/` 目录 `750`
- `state/`：`750`；`state/*.json` 含缓存/备份，保持 `640`
