## 5. 服务端侧可下的 / 不可下的结论

**能下：**
1. 服务端**没有**任何 30 秒级的处理耗时（最大 1.57 s）。
2. 黑屏窗口内**没有**任何资源类（`static*`）新连接。
3. 客户端在这 30 秒里**有**网络活动，但对象是 tap/yostar/阿里云号码认证等**外部 SDK**，以及我们自己那条 keep-alive 会话。

**不能下（留给 pcap / 客户端侧）：**
1. 那 30.152 s 的 `dypnsapi-dualstack.aliyuncs.com` 会话里客户端在等什么（我们只透传，看不到内容）。
2. 我们那条 8443 会话是**客户端先关**还是**服务端先关**（需要 pcap 的 FIN/RST 方向）。
3. 黑屏与"哪个外部连接超时"之间是否有因果关系 —— 时间重合只是**相关**，不是**因果**。
