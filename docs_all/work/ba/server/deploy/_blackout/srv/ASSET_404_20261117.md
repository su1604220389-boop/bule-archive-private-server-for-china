## 4. `ba_sni.conf` 全量规则（原文）

```nginx
map $ssl_preread_server_name $ba_host {
    default                     $ssl_preread_server_name;
    ~*^[0-9.]+$                 127.0.0.1;                      # IP 作 SNI -> 死端口
    ~*^static(-qc|-hs)?\.bluearchive-cn\.com$   $ssl_preread_server_name;   # static 强制透传
    ""                          127.0.0.1;                      # 无 SNI -> 我们
    ~*^bluearchive-cn\.com$     127.0.0.1;
    ~*\.bluearchive-cn\.com$    127.0.0.1;                      # ★ 其它任意子域 -> 我们
    ~*^example\.com$       127.0.0.1;
    ~*\.example\.com$      127.0.0.1;
}
map $ssl_preread_server_name $ba_port {
    default                     443;
    ~*^[0-9.]+$                 1;
    ~*^static(-qc|-hs)?\.bluearchive-cn\.com$   443;
    ""                          8443;
    ~*^bluearchive-cn\.com$     8443;
    ~*\.bluearchive-cn\.com$    8443;
    ~*^example\.com$       8443;
    ~*\.example\.com$      8443;
}
server { listen 443; ssl_preread on;
    resolver 223.5.5.5 119.29.29.29 114.114.114.114 valid=60s ipv6=off;
    resolver_timeout 10s; proxy_connect_timeout 5s; proxy_timeout 600s;
    proxy_buffer_size 16k; proxy_pass $ba_host:$ba_port; }
```
**判读（风险点，事实陈述）：**
- 只有 `static(-qc|-hs)?.bluearchive-cn.com` 走真实 CDN。
- **其它任何 `*.bluearchive-cn.com`（例如 `rs.` / `cdn.` / `download.` / `asset.`）都会落到 `127.0.0.1:8443`**，而 8443 上只有 `state-api*/gsqc-api*/gs-api*/static*` 四个 server_name；不匹配的 SNI 会落到 `default_server`（state-api 块）→ `location /` → `proxy_pass http://127.0.0.1:5000`（Shittim）→ 返回 404，**并在 `ba_raw.log` 留一行**。
- **本窗口内没有任何这样的行** ⇒ 本轮客户端**没有**去请求除 static 以外的资源子域（至少没有经过 843/8443 这条）。

## 6. 本轮能下与不能下的结论

**能下：**
1. 本窗口 **没有** 任何资源类请求打到我们的 vhost；**没有** 404/5xx/499（唯一非 200 是 19:36:45 的空请求 400）。
2. 那 5 个 CLOSE_WAIT 远端**都不是我们**。

**不能下（说清楚，不替你圆）：**
1. `static*` 是 stream 层透传，**我们看不到它的 HTTP 状态码**；所以"客户端是否从 CDN 拿到了残缺/空的 bundle"**服务端无法判定**。
2. 客户端若走的是**不经过我们**的地址（DNS 直连真实 CDN），我们更是零可见性。
3. 因此"资源加载失败"这个**客户端侧结论**，服务端只能提供"**不是我们回错了包**"这半边证据；另外半边（bundle 是否损坏/缺失、音频资源是否 404）必须从**手机侧**（Unity 的 `Player.log` / `adb logcat` 里的 Addressables 报错）取。
