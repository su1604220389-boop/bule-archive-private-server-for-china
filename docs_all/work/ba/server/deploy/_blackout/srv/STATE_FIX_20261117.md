## ⑤ 判定（三句）

1. **116 B 里有什么**：只有 `Servers` 三条 API 地址 + `State/Msg`。**缺 8 个字段**，包括 4 个版本号与 3 条 `AddressablesCatalogUrlRoots`。
2. **官方 `state-api` 该长什么样**：我们手上**没有**来自官方 `state-api` 的原始样本（`cn_real_capture/state_real.json` 是 676 B 那份，来源应是 `gsqc-api`）。**"官方 state-api 是 116 B 还是 676 B"这一点，目前证据不足，不能断言。** 但可以确定：**116 B 这份是"手搓最小版"，不是抓包样本。**
3. **客户端拿两条做什么**：从调用顺序看，`state-api` 更像"先拿一个能解析的壳（Servers）"、`gsqc-api` 才是"拿完整配置"的那条。**若 `state-api` 也该带版本号，那它现在缺版本号确实会让客户端认为"无需更新"——但这仍是推断，不是证据。**

## ⑥ 若要验证（**只出方案，不执行**）

**方案 V1（最小改动、只读可控）**：把 `_ba_state/state-api/api-state.json` 从 116 B 换成一个**保留 `Servers` + 补 4 个版本号 + 3 条资源根**的版本（约 560 B），**不补 `IsOpenPreDownload`（或设 false）**。
