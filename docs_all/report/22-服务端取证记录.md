## 0. 结论摘要

1. **TLS 已经不是瓶颈。** 手机 `UnityPlayer/2021.3.56f2 (UnityWebRequest/1.0, libcurl/8.10.1-DEV)` 对
   `state-api.bluearchive-cn.com` **4 次**完成 TLS 1.2 握手（ClientHello → 证书 flight → ClientKeyExchange → CCS → Finished → 339 B 应用数据），
   nginx 解出明文 `GET /api/state` 并回 **200**。
2. **01:33:45 是分水岭。** 该时刻之前，手机对我们的证书回 **46 条明文 `fatal alert 49 access_denied`**（TLS 1.2 连接可读）；
   之后**一条 alert 都没有**，01:34:52 起同一条链路直接 200。⇒ CA 真正生效时刻 = **01:33:45**。
3. **卡点判断必须收窄 —— 后经手机侧实测推翻「看不到」的顾虑。** 手机侧是 **按 uid + 端口全量 DNAT**（`uid 10576` 的所有 IPv4:443 → `<SERVER_IP>:443`），
   conntrack 证实 `dst=39.107.57.56` / `dst=111.3.79.60` 的 `reply src` 都被改写。⇒ **我们服务器上的 pcap 就是全量的**，
   「服务端无记录」在本场景下可以等同于「客户端没发」。判断依据从「看不到」改为「全量劫持」。
4. **01:42:19 客户端确实发出了下一跳**：同一秒并发 4 条 TLS — `state-api`(CH 1561)、`gsqc-api`(1412)、`static.bluearchive-cn.com`(1412)、无 SNI(1412)，
   服务端 flight ≈4091 B，但 **access log 里 `static|gsqc|gs-api` 计数 = 0** —— 握手之后没形成任何完整 HTTP 请求。这才是「挂住」的现场。
5. **证书目录已被换成 `ca2/chain.crt`**（`CN=BA Test Root CA`），与 `ca3/chainS.crt`（伪装 `RapidSSL TLS RSA CA G1`）是**两套不同信任锚**。
   `ca2/ca.crt` = **1164 B**，与手机信任库里装的那个文件同尺寸 ⇒ 手机信任的是 ca2 的根。**切回 ca3 会立刻复现 46 条 alert 49。**

## 4. 判读（对齐 Lead 口径）

| 口径 | 观测 | 判定 |
|---|---|---|
| flight 之后出现 `GET`/`POST`/`PRI *` | flight 后是 `APP(339)`，nginx 解出 `GET /api/state` 并 200 | ✅ **TLS 通过（state-api）** |
| `15 03 03 00 02 XX` 明文 alert | 46 条，全 `XX=49`，全部 ≤01:33:45 | ❌ 该时段被拒；01:33:45 后消失 |
| `14 03 03 00 01 01` + `17 03 03`（19 B） | 大量，但为 TLS 1.3 加密 alert/close_notify，非 42/46/48 | 与 BA 主流无关（SNI 均为非 BA 域名，或为正常关闭） |
| 完全无 ClientHello | 有 | 不适用 |

**`access_denied(49)` 的性质**：Android/Conscrypt 走应用层 TrustManager 判定时常用 49 而非 46/48；
本机实测 49 出现在「证书链未被接受」阶段（CCS 之前），CA 生效后立即消失。这条**不能**单凭 49 就断定是 pinning——
真 pinning 也会在这个位置报 49，但本轮 49 的消失与 CA 生效严格同步，指向 trust store 而非 pinning。

## 17. MTR 可行性

```console
net.ipv4.tcp_syncookies = 1
net.ipv4.icmp_echo_ignore_all = 0
-P INPUT DROP（IN_BT / ufw 链）
```
**结论：不是拦路虎。** TTL 只影响转发，目的地址是本机时内核不看 TTL，照常回 SYN-ACK；
且手机侧 DNAT 在 `nat OUTPUT` 就改写目的地址，探测包一跳直达 → MTR 显示 1 跳到达，即「成功」。
唯一可能拦的是 `-P INPUT DROP`，但 443 实测放行。
