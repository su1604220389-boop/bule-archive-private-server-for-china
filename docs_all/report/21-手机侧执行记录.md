## 3. 与 Lead 命令清单的偏差（执行层面，均已验证原因）

1. **`sendevent /dev/input/event2` → 改用 `/dev/input/event5`**：`getevent -p` 实测 event2 = `pmic_pwrkey`（电源键），event5 = `touchpanel`；写 event2 只会按电源键。
2. **坐标不是「1080×2400 估」**：面板 1272×2800，`ABS_MT_POSITION_X max 20351 / Y max 44799`＝像素×16；屏幕中心 = raw(10176, 22400)。游戏是横屏 2800×1272，屏幕中心在旋转后仍是中心，故中心点击不受旋转映射影响；但要点**具体按钮**必须先解出旋转映射（本轮未解，只点了中心）。
3. **`logcat -d -b all -v time -s \| grep`** 里 `-s` 是「只看这些 tag」，后面没给 tag 会输出空 → 实际执行改为 `logcat -d -b all -v time > /sdcard/r2_full.txt` 再 grep。
4. **`grep -E ' E | F | W '` 匹配不到 `-v time` 格式**（级别是 `E/Tag`，不是空格夹级别）→ 改用 `' [EFW]/'` 与按 pid 过滤。
5. **`am force-stop` 必然失败**（`Failed transaction`），已按预案用 `kill -9` 兜底，并验证进程确实死透。

  - **标题页正常加载**（插画完整渲染，Unity 视频解码 1568×720@30fps 正常）。
