## 1. 一句话现状

**文档里同时存在两个「当前版本」锚点，且互不一致：最后一份「能正常进游戏」的完整包是 E42；而实验推进到的最新一版是 E64（仅 libil2cpp 注入验证版）。卡点只有一个：客户端第一个网关主机名的来源未定位。**

- **E42（现役可用包）**：「E42：官方资源基线 + 原厂 `libunity` + 我们的 `res`（卡密文案）+ `assets/SDKConfigSettings.json`（`sdk_url` 指本机）+ 删 `__tpinfo`」（`ba-pitfalls.md:149`）；「**现役可用包：E42**（2,126,782,882 B）」（`ba-pitfalls.md:155`）。表现原文：「能进主程序、SDK 卡密登录通过、停在「认证服务器拒绝了请求」（网关仍是官方）」（`ba-pitfalls.md:150`）。
- **E64（最新实验版）**：「**未完成**：把 GOT 改写 + 真函数指针持久化（RW bss）这一版做稳，E64 表现从「被官方拒绝」变成「超时」，说明路径已改但实现仍有阻塞」（`ba-pitfalls.md:184`）。E63 为「注入代码内调用 `dlopen("libc.so")+dlsym("getaddrinfo")` 后 tail-call 真函数 → ✅ 可用（E63 alive=24049）」（`ba-pitfalls.md:172`）。
  - 注：E64 是「注入版 libil2cpp」的验证编号，归档 README 未把它列为可交付包；README 结论是「**尚未达到「进大厅」的交付标准**」（`README_归档说明.md`「当前进度」）。
- **卡在哪一步（卡点原话，两处）**：
  1. 「## 四、当前唯一未解的问题（一句话）／**「客户端第一次连接网关前，那个主机名是从哪来的」**——静态三边 + 表包 + 两个落盘配置全部排除，只剩「运行时解密」这一种可能。」（`ba-gateway-host.md:103-105`）
  2. 「**唯一还没试完的一条**：`libil2cpp.so` 已验证可改（E38 正常启动），下一步是在其中定位网关地址的产生点（静态/运行时均可，因为不再受 ACE 限制）」（`ba-pitfalls.md:159`）
- **客户端侧最终表现**：「枪毙在游戏自己的网关：原生弹窗「认证服务器拒绝了请求，将返回标题画面」」（`ba-gateway-host.md:15`）。


- **[已验证] 服务端只开 HTTP**：「服务端只开 HTTP（Kestrel 在代码里禁用 HTTPS）」（`ba-pitfalls.md:40`）；因此上一环必须是 TLS 终止（`ba-pitfalls.md:40`、`README_归档说明.md`「服务器侧脚本」列 `ba_mitm.conf（443 SNI 分流）`）。
- **[已验证] 卡密 SDK 可跑**：「必须常驻：`/root/bapatch/sdkcard.py`（卡密服务，`0.0.0.0:8080`）。设备每次重启后要手动拉起」（`ba-pitfalls.md:156`）；「输 `11111111111` 返回 200 + token」（`ba-gateway-host.md:10`）。
- **[已验证] 卡密设计口径**：卡密不在游戏内做 UI，插在 `/user/quick-login` 之前，无卡密只回错误码（`ba-sdk-protocol.md §四`）。
- **[已验证] 数据层是硬卡点**：「`SchaleAI.InitializeSchale`（**需要玩法表，当前卡点**）」（`ba-data-layer.md:36`）；玩法表不在客户端任何下载资源里（`ba-data-layer.md §一`）；`CharacterExcel: skipped 7223 unreadable row(s), loaded 0` → 必须用 Shittim `v2026.8.8`（`ba-pitfalls.md:36`）。
- **[已验证] 协议层可直接移植**：1147 个协议号、66 个 handler、三个 Newtonsoft converter（`ba-protocol-full.md §三/§六/§七`）。
- **[未验证]** nginx 与 443 SNI 分流的具体配置内容（`patch_nginx.sh` 只做 `location = /` 探针与 `proxy_pass`）——audit 文档内未记录该环的验证结论，属**推断**（依据 `deploy.sh`/`patch_nginx.sh` 脚本本体，非文档结论）。
- **[未验证]** 客户端到我们服务器的这一跳从未打通：「剩下「把网关请求导到我们服务器」最后一步未打通」（`README_归档说明.md`「当前进度」）；`ba-pitfalls.md:184` 同义。
