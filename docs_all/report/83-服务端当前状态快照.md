## 6. 已确认的事实（可直接引用，不必重测）

1. **CN 响应封装**：`base64(AES-256-CBC(key 随机, IV="JOSYdf8ys97uhFYS", PKCS7(明文)) + key)`，无 gzip、无长度前缀、IV 不随包传输。
2. **`Protocol` 两层不同**：外层 `protocol` = 名字字符串（小写键名）；内层 `Protocol` = **整数**。
3. **协议号可从请求直接读出**：`Hash >> 32`，实测对上 `1002 / 1001 / 1010 / 1019 / 24000`。
4. **客户端 base53 token 算法**：`base32(MD5(UTF16LE(协议名)))`（去 `=`），三次逐字符命中。
5. **`SyncProtocols` 实测为 `[]`**（客户端不点名）。
6. **客户端从未主动发过 `Account_LoginSync`(1019)**；历史上 4 条 1019 全部是 srv-ops 的 curl。
7. **`/api/state` 与真服逐键相同**（10 键、676 B），`AddressablesCatalogUrlRoots` 三条 `/prodm39` 一致。
8. **资源清单五连在真 CDN 全 200**：路径规则见 `report/61`、`report/62` 前身记录。
