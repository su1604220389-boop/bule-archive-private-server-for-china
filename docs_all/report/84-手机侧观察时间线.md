## 5. 网络侧观察（手机本地，作为界面观察的旁证）

| 项目 | 值 |
|---|---|
| 劫持机制 | 唯一一条 `iptables -t nat OUTPUT`：`! -d <SERVER_IP>/32 -p tcp -m owner --uid-owner 10576 --dport 443 -j DNAT --to <SERVER_IP>:443`（**按 UID+端口全量劫持，不看域名**） |
| 直连放行 | 16 条 `ACCEPT`（CDN 真 IP 白名单）插在 DNAT 之前，顺序正确 |
| hosts | **干净**（无 bluearchive 条目） |
| DNS | 手机解析 `static*.bluearchive-cn.com` → `120.226.195.66` / `112.15.9.222` / `112.15.9.226`（真 CDN） |
| IPv6 | `ip6tables nat` 表不存在；`ip6tables OUTPUT` 对 uid 10576 的 443 是 **REJECT** |
| 手机→真 CDN 实测 | 6.55 MB 文件 **0.36–0.63 秒**（root, curl, 带 SNI, `verify=0` 通过） |
| 游戏进程→CDN | 曾出现 `CLOSE-WAIT, rx=1 字节`（120.226.195.66），随后 CDN 直连规则命中（ACCEPT #1/#16 计数增长） |

**已排除的假设**：证书链缺 intermediate / CA 库被破坏 / 版本号导致 404 / TLS 版本协商失败。

## 8. 下次接手时的建议

1. **不要用文件体积判断弹窗** → 用 `_tmp/chkcard.py` 像素检测
2. **不要因为「点击任意区域进入游戏」不可见就说不能点** → 那是呼吸动画
3. **连拍用 `setsid` 后台 + 轮询日志**（前台 `for` 循环会被连接重置打断）
4. **1 秒/帧仍会漏掉短暂界面**（实际 1.5–1.8 秒/帧）→ 短暂界面以用户口述为准
